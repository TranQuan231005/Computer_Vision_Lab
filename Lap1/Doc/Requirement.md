# Exercise Requirements

1. Install the OpenCV and Pillow libraries

2. Read and display images
   - Read any image from the computer.
   - Display that image on the screen.
   - Save the processed image in a different format.

3. Color space conversion
   - Convert the image from RGB to grayscale.
   - Convert the image to other color spaces such as HSV, LAB.

4. Cropping and resizing
   - Crop any region of the image.
   - Resize the image by scale or fixed dimensions.

5. Draw basic shapes
   - Draw basic shapes such as lines, circles, and rectangles on the image.
   - Add text to the image.
